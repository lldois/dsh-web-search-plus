# dsh-web-search-plus

Enhanced native web search provider for DeepSeek Harness (DSH).

Unlike the shipped official search provider which discards model-generated synthesis and keeps only raw links, `dsh-web-search-plus` captures **both** the full synthesized answer and deduplicated sources with citation snippets across Anthropic-compatible reverse proxies and gateway endpoints (such as Gemini 2.5 / 3.x proxies, CPA, OneAPI, NewAPI, and Claude endpoints).

## Key Features

- **Full Synthesized Content**: Preserves rich markdown summaries and search analysis generated by the model.
- **Accurate Source Attribution**: Automatically pairs URLs with cited text snippets from citation blocks.
- **Universal Anthropic Wire**: Speaks standard `/v1/messages` with `web_search_20250305`.
- **Configurable Budgets**: Defaults to 8 search uses and 8192 output tokens for thorough multi-turn search tasks without requiring high reasoning overhead on the main model.
- **DSH Native Integration**: One-line Cordis bundle registration through `cordis.patch.yml`.

## Installation

Install directly into your DSH profile:

```bash
dsh plugin --profile web add github:lldois/dsh-web-search-plus
```

Or for local development / testing:

```bash
dsh plugin --profile web add /path/to/dsh-web-search-plus
```

## Configuration

You can configure options in DSH Settings UI under **Plugin configuration -> Web search plus**, or in your profile's `cordis.patch.yml` / `settings.yaml`:

| Option | Default | Description |
|---|---|---|
| `baseURL` | `http://100.78.146.24:8317/v1` | Base URL of your Anthropic Messages endpoint (`/v1` or `/v1/messages`) |
| `apiKeyEnv` | `WEB_SEARCH_API_KEY` | Environment variable name holding the API token |
| `apiKey` | (optional) | Direct literal API key |
| `model` | `gemini-3.7-flash-high` | Target search model |
| `maxUses` | `8` | Maximum tool calls per search query |
| `maxTokens` | `8192` | Maximum generated tokens for search answers |
| `apiVersion` | `2023-06-01` | `anthropic-version` header value |

## Optional: Manually Disable the Shipped Search Provider

If you prefer to explicitly disable the official `web-search-deepseek` plugin, add the following to your profile\'s `cordis.patch.yml`:

```yaml
- id: web-search-deepseek
  disabled: true
```
